# 阅集图书商城实验要求追踪矩阵

版本：1.0｜原始依据：《实验四：【项目实战】企业级应用——XX商城系统.docx》。

## 1 原文分类原则

下表按原文标题和条目定位，不虚构 Word 页码。实验描述给出的是必做目标与技术示例；建议栈中出现 Spring Cloud、Nacos、K8s 等不等于每项都必须采用。原文要求对“所有用到的”企业级技术和环境截图说明，未采用项应在选型中说明原因，不制作假安装截图。

范围已确定为多商家图书商城。业务政策、技术组合和性能阈值属于项目设计决策；原文鼓励的创新并不自动进入首版。

## 4 本次审阅结论边界

文档审阅只确认需求和设计有明确对应，不确认实现已完成。实施阶段在本表新增“实际版本、测试证据、当前状态、责任人”列，并逐项填写。未采用示例组件必须在 ADR 有理由，未达到指标必须在实测报告有记录，不为凑满矩阵虚构证据。
