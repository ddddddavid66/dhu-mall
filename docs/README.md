## 唯一事实来源

需求编号、范围与业务政策以 01 为准；状态机与事务边界以 02 为准；持久化字段以 03 为准；网络字段和错误码以 04 为准；页面以 05 为准。其他文档通过引用使用这些规则，不另行定义同名概念。发现冲突时暂停受影响部分，提交变更说明并同步更新相关文档，不能由模型私自选择一种行为。

所有金额使用人民币、精度两位；接口用十进制字符串传输。所有 ID 用字符串传输。存储时间为 UTC，接口使用带 Z 的 ISO 8601，页面按 Asia/Shanghai 展示。
