# 阅集图书商城设计文档包

版本：1.0｜编制日期：2026-10-03｜状态：设计基线；业务与页面已实施至阶段 G。阶段 H 于 2026-10-26 执行质量验证，后端 119 项测试通过，但 Maven clean verify 因服务分支覆盖 72.51% 低于 80% 门槛而失败。阶段 I 已生成容器/CI/监控和 test 发布恢复产物，当前无实际 CI run、Linux 部署或备份恢复；不标为阶段通过或可发布。

实际实现与验证状态见 [项目根 README](../README.md)、[阶段 H 交接](stages/H-验证与交接.md)、[阶段 I 交接](stages/I-验证与交接.md)、[阶段 I 发布与恢复清单](stages/I-发布与恢复清单.md)、[阶段 I AI 使用记录](stages/I-AI使用记录.md)、[阶段 I 机器证据](stages/evidence/I-verification.json)、[阶段 G 交接](stages/G-验证与交接.md)、[阶段 F 交接](stages/F-验证与交接.md) 和 [阶段 E 交接](stages/E-验证与交接.md)。G 的前端页面和本地联调边界见 G 交接；API-89 仍真实返回未实现。H 的服务分支覆盖门槛未通过；I 的容器解析通过但实际 Docker/CI/Linux 部署、TC-26—31 验收仍未执行；真实沙箱仍待提供。下文“本次设计交付”的限制用于描述原始设计包，不限制后续明确授权的实施阶段。

本包面向后续负责实现的模型和开发者，将课程实验要求转化为统一的需求、设计和验收依据。业务为多商家实体新书商城；采用 Java 与 Vue、模块化单体、支付宝沙箱和单机容器部署。

本次仅提供设计。数据库字段表不等于建表脚本，接口目录不等于已实现接口，环境步骤不等于可直接运行的命令，测试目标不等于实测结果。不包含业务代码、SQL、OpenAPI YAML、Dockerfile、Compose 或 CI 工作流文件；其生成工作由后续实现模型依据本包完成。

## 唯一事实来源

需求编号、范围与业务政策以 01 为准；状态机与事务边界以 02 为准；持久化字段以 03 为准；网络字段和错误码以 04 为准；页面以 05 为准。其他文档通过引用使用这些规则，不另行定义同名概念。发现冲突时暂停受影响部分，提交变更说明并同步更新相关文档，不能由模型私自选择一种行为。

所有金额使用人民币、精度两位；接口用十进制字符串传输。所有 ID 用字符串传输。存储时间为 UTC，接口使用带 Z 的 ISO 8601，页面按 Asia/Shanghai 展示。
