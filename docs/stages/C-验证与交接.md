## 3 实施约束

商品首次建立 DRAFT，一个 Product 只有一个 SKU；同店同书与 skuCode 有数据库唯一约束。价格修改同一事务递增商品与 SKU 版本，纯介绍修改只递增商品版本；库存版本独立。上架核对店铺、书目、分类及父分类有效，公开列表/详情同样检查，缺货可以展示，但新加入或重新勾选购物车必须满足可购买条件；已有失效项允许取消勾选或删除。

运营 offShelf=true 可下架；false 保留现有状态、只处理精选意图，不转换为 ON_SALE，下架原因写入审计摘要。分类最多两级，拒绝环；停用含有效书目的分类失败；已被 Product 引用的 ISBN 不改号。所有 ID/金额继续使用既有字符串类型，JSON 拒绝未知字段、小数截成整数或字符串隐式强转。

人工库存调整先核对本店和动作权限、锁用户及 SKU 库存，核对 version 后以条件更新只改变 on_hand；reserved 不变，结果必须满足 0≤reserved≤on_hand≤4294967295。幂等按用户/操作/键唯一，绑定路径及请求摘要；相同请求返回原始业务快照，异参/处理中/过期分别冲突，24 小时重放、30 天保留。库存、流水、审计及快照同事务成功或回滚。

文件仅 JPEG/PNG/WebP，≤5MB，核对扩展名、MIME、真实解码格式，限制长宽/像素，统一重编码 PNG；拒绝路径式文件名、伪图和超限内容，随机存储键不采用原文件名。public/private 分目录，存储根不作为 Spring 静态资源，私有 url 为空且下载响应 no-store。私有下载必须当前会话与 file.private.read，再校验本人或真实售后关联；仓库还需本店 WAREHOUSE 和关联退货。未关联的客服/仓库不得读凭证。生产 FILE_STORAGE_ROOT 必须显式配置，Nginx 只能映射公开目录，不能映射整个存储根。

本阶段读请求直接查询 MySQL，没有启用 Redis 或伪称缓存命中。展示数据可能在响应后变化，购物车不是预占；阶段 D 必须再次核对数据库价格版本、状态及库存。公开读默认每 IP 120 次/分钟，写每用户 30 次/分钟；联调脚本遵守实际限流，不修改服务器阈值。
